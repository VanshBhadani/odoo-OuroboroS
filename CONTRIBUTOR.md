# StockSense Contributors

This document highlights the core team members who contributed to the development, design, and quality assurance of the StockSense application.

---

## Team Members & Roles

### 1. Aesha Gupta
**Role:** Backend Developer & Database Architect  
**Key Responsibilities:**
- Designed and implemented the core database schema using PostgreSQL and SQLAlchemy.
- Developed the RESTful API endpoints using FastAPI for inventory management, operations, and settings.
- Implemented secure authentication and authorization flows (JWT, bcrypt).
- Engineered the core inventory logic (ACID transactions, stock quant updates, and ledger tracking).
- Managed backend routing, data validation, and Pydantic schemas.

### 2. Vansh Bhadani
**Role:** Frontend Developer & UI/UX Designer  
**Key Responsibilities:**
- Built the responsive and dynamic user interface using Next.js and React.
- Designed the application's premium aesthetic using Tailwind CSS.
- Developed interactive components including the dashboard, product catalog, receipt generation, and settings panels.
- Integrated the frontend client seamlessly with the FastAPI backend.
- Ensured a seamless user experience (UX) focusing on dynamic interactions and state management.

### 3. Alok Singh
**Role:** Quality Assurance (QA) Tester  
**Key Responsibilities:**
- Developed and executed comprehensive test plans for both frontend and backend systems.
- Conducted API endpoint testing to ensure data integrity and proper error handling.
- Identified, tracked, and reported bugs during the development lifecycle.
- Validated end-to-end user workflows (e.g., login flows, inventory operations, and PDF generation).
- Ensured the overall stability, security, and performance of the application prior to deployment.
